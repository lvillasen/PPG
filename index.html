Código Fuente

Un fotopletismógrafo (PPG, por sus siglas en inglés: Photoplethysmograph) es un dispositivo óptico que mide los cambios en el volumen sanguíneo en los tejidos, generalmente en la piel, usando luz.


Términos de Uso y Descargo de Responsabilidad

El fotopletismógrafo es un instrumento y una aplicación web desarrollados exclusivamente con fines educativos y de investigación. Este dispositivo no cuenta con certificación como equipo médico ni cumple con las normativas regulatorias requeridas para su uso clínico.

La información proporcionada por el sistema, incluyendo valores de la frecuencia cardiaca y parámetros derivados de la onda de pulso, es de carácter experimental y puede contener errores o inexactitudes.

Por lo tanto:

  • No debe utilizarse para diagnóstico médico, tratamiento o monitoreo clínico.
  • No debe emplearse para la toma de decisiones médicas o ajuste de medicación.
  • No sustituye la evaluación, diagnóstico ni recomendaciones de un profesional de la salud calificado.

El uso de este sistema es bajo la responsabilidad del usuario. Los desarrolladores no se hacen responsables por cualquier daño, perjuicio o consecuencia derivada del uso indebido de la información generada por el dispositivo y su software.

Se recomienda que cualquier medición de la frecuencia cardiaca y forma de pulso con fines clínicos se realice utilizando dispositivos certificados y bajo supervisión médica.


Su funcionamiento es el siguiente:

  1. Usa una fuente de luz (LED verde):
    • Se coloca en contacto con la piel (dedo, muñeca, lóbulo de la oreja).
    • Emite luz hacia el tejido.
  2. Interacción con la sangre y tejidos:
    • Parte de la luz se absorbe por la hemoglobina en la sangre.
    • Parte se refleja o atraviesa el tejido.
  3. Fotodetector:
    • Registra la luz transmitida o reflejada.
    • La cantidad de luz detectada cambia en función de la cantidad de sangre presente en los vasos.
  4. Señal PPG:
    • AC (pulsátil): varía con cada latido cardíaco → refleja la onda de pulso arterial.
    • DC (lenta): depende de factores como respiración, tono vascular o temperatura.

Existen 2 tipos de fotopletismógrafos:

  • Transmisivo: la luz pasa a través del tejido (ej. dedo en un oxímetro de pulso).
  • Reflectivo: el detector está al lado del LED y mide la luz reflejada (ej. relojes inteligentes).

Sus principales aplicaciones son las siguientes:

  1. Medición de frecuencia cardíaca (pulso).
  2. Oxímetro de pulso (SpO₂): usando dos longitudes de onda (rojo e infrarrojo) se estima la saturación de oxígeno en la sangre.
  3. Variabilidad de la frecuencia cardíaca (HRV).
  4. Estimación de presión arterial (usando algoritmos y calibraciones).
  5. Detección de arritmias.
  6. Monitorización del sueño.
  7. Medición de la velocidad de onda de pulso (PWV): en combinación con otro sensor (como en tus experimentos de carótida–femoral) sirve para estimar la rigidez arterial.

Codigo para programar el microcontolador ESP32 usando Arduino IDE. Este código permite leer la señal del sensor PPG usando el ADC externo ADS1115 de 16 bits a razón de cerca de 860 Hz y mandar los datos a la PC a través del puerto serie a 115200 baudios. 

      
      
      #include <Adafruit_ADS1X15.h>

      Adafruit_ADS1115 ads;
      unsigned long prevMicros = 0;

      void setup() {
        Serial.begin(115200);

        Wire.begin();
        Wire.setClock(400000);  // más seguro que 800 kHz

        if (!ads.begin(0x48)) {
          Serial.println("Error: No se encontró el ADS1115 en 0x48");
          while (1);
        }

        ads.setGain(GAIN_TWOTHIRDS);                 // ±6.144 V
        //GAIN_TWOTHIRDS = ±6.144 V → 0.1875 mV por cuenta.
        ads.setDataRate(RATE_ADS1115_860SPS);        // 860 muestras por segundo
        ads.startADCReading(ADS1X15_REG_CONFIG_MUX_SINGLE_0, true); // canal A0
      }

      void loop() {     
        // Leer ADS1115
        int16_t sensor = ads.getLastConversionResults();
        // Convertir a volts
        float volts = sensor * 0.1875f / 1000.0f;
        // Lanzar siguiente conversión inmediatamente
        ads.startADCReading(ADS1X15_REG_CONFIG_MUX_SINGLE_0, true);
        // Tiempo en ms
        float t_ms = microsNow * 0.001f;
        // Buffer de salida
        char line[48];
        
        int len = snprintf(
            line,
            sizeof(line),
            "%.4f %d %.2f\n",
            volts,
            sensor,
            t_ms
        );
        Serial.write((uint8_t*)line, len);    
      }
